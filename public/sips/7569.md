## Abstract

This Meta SIP lists the SIPs included in the Dencun network upgrade across both Sila's execution and consensus layers. See [SIP-7568](./sip-7568.md) for the specifications of past upgrades.

## Specification

### Included SIPs 

* [SIP-1153](./sip-1153.md): Transient storage opcodes
* [SIP-4788](./sip-4788.md): Beacon block root in the SAVM
* [SIP-4844](./sip-4844.md): Shard Blob Transactions 
* [SIP-5656](./sip-5656.md): MCOPY - Memory copying instruction
* [SIP-6780](./sip-6780.md): SELFDESTRUCT only in same transaction
* [SIP-7044](./sip-7044.md): Perpetually Valid Signed Voluntary Exits
* [SIP-7045](./sip-7045.md): Increase Max Attestation Inclusion Slot
* [SIP-7514](./sip-7514.md): Add Max Epoch Churn Limit
* [SIP-7516](./sip-7516.md): BLOBBASEFEE opcode

### Full Specifications 

#### Consensus Layer

SIPs 4788, 4844, 7044, 7045 and 7514 require changes to Sila's consensus layer. These are specified in the `deneb` folder of the `sila/consensus-specs` repository.

#### Execution Layer

SIPs 1153, 4788, 4844, 5656, 6780 and 7516 require changes to Sila's execution layer. The SIPs fully specify the changes.
