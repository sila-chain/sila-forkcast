## Abstract

This Meta SIP lists the SIPs which belong to the EVM Object Format (EOF) proposal, in its first version (EOFv1), also known as the "Mega EOF".

## Specification

### SIPs Included

Introduced in eof-devnet-0

- [SIP-3540](./sip-3540.md): EOF - EVM Object Format v1

- [SIP-4750](./sip-4750.md): EOF - Functions
- [SIP-5450](./sip-5450.md): EOF - Stack Validation
- [SIP-6206](./sip-6206.md): EOF - JUMPF and non-returning functions
- [SIP-7480](./sip-7480.md): EOF - Data section access instructions
- [SIP-663](./sip-663.md): SWAPN, DUPN and EXCHANGE instructions
- [SIP-7069](./sip-7069.md): Revamped CALL instructions
- [SIP-7620](./sip-7620.md): EOF Contract Creation
- [SIP-7698](./sip-7698.md): EOF - Creation transaction
