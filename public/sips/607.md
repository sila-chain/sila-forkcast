## Abstract

This specifies the changes included in the hard fork named Spurious Dragon.

## Specification

- Codename: Spurious Dragon
- Aliases: State-clearing
- Activation:
  - Block >= 2,675,000 on SilaMainnet
  - Block >= 1,885,000 on Morden
- Included SIPs:
  - [SIP-155](./sip-155.md) (Simple replay attack protection)
  - [SIP-160](./sip-160.md) (EXP cost increase)
  - [SIP-161](./sip-161.md) (State trie clearing)
  - [SIP-170](./sip-170.md) (Contract code size limit)
