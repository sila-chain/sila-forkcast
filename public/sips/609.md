## Abstract

This specifies the changes included in the hard fork named Byzantium.

## Specification

- Codename: Byzantium
- Aliases: Metropolis/Byzantium, Metropolis part 1
- Activation:
  - Block >= 4,370,000 on SilaMainnet
  - Block >= 1,700,000 on Ropsten testnet
- Included SIPs:
  - [SIP-100](./sip-100.md) (Change difficulty adjustment to target mean block time including uncles)
  - [SIP-140](./sip-140.md) (REVERT instruction in the Sila Virtual Machine)
  - [SIP-196](./sip-196.md) (Precompiled contracts for addition and scalar multiplication on the elliptic curve alt_bn128)
  - [SIP-197](./sip-197.md) (Precompiled contracts for optimal ate pairing check on the elliptic curve alt_bn128)
  - [SIP-198](./sip-198.md) (Precompiled contract for bigint modular exponentiation)
  - [SIP-211](./sip-211.md) (New opcodes: RETURNDATASIZE and RETURNDATACOPY)
  - [SIP-214](./sip-214.md) (New opcode STATICCALL)
  - [SIP-649](./sip-649.md) (Difficulty Bomb Delay and Block Reward Reduction)
  - [SIP-658](./sip-658.md) (Embedding transaction status code in receipts)
