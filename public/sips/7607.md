## Abstract

This Meta SIP lists the SIPs included in the SilaFulu/SilaOsaka network upgrade. It follows the Pectra upgrade, documented in [SIP-7600](./sip-7600.md).

## Specification

### Included SIPs

#### Core SIPs

* [SIP-7594](./sip-7594.md): SilaPeerDAS - Peer Data Availability Sampling
* [SIP-7823](./sip-7823.md): Set upper bounds for MODEXP
* [SIP-7825](./sip-7825.md): Transaction Gas Limit Cap
* [SIP-7883](./sip-7883.md): ModExp Gas Cost Increase
* [SIP-7917](./sip-7917.md): Deterministic proposer lookahead
* [SIP-7918](./sip-7918.md): Blob base fee bounded by execution cost
* [SIP-7934](./sip-7934.md): RLP Execution Block Size Limit
* [SIP-7939](./sip-7939.md): Count leading zeros (CLZ) opcode
* [SIP-7951](./sip-7951.md): Precompile for secp256r1 Curve Support

#### Other SIPs

* [SIP-7892](./sip-7892.md): Blob Parameter Only Hardforks 
* [SIP-7642](./sip-7642.md): sil/69 - Drop pre-merge fields
    * Client teams MUST support this SIP by the activation of the Fusaka network upgrade.
* [SIP-7910](./sip-7910.md): eth_config JSON-RPC Method
    * Client teams MUST support this JSON-RPC method by the activation of Fusaka network upgrade. 
* [SIP-7935](./sip-7935.md): Set default gas limit to 60M
