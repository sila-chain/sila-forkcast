## Abstract

This Meta SIP lists the SIPs Included in the SilaPrague/Electra network upgrade. It follows the Dencun upgrade, documented in [SIP-7569](./sip-7569.md).

## Specification

### Included SIPs

#### Core SIPs

* [SIP-2537](./sip-2537.md): Precompile for BLS12-381 curve operations
* [SIP-2935](./sip-2935.md): Save historical block hashes in state
* [SIP-6110](./sip-6110.md): Supply validator deposits on chain
* [SIP-7002](./sip-7002.md): Execution layer triggerable exits
* [SIP-7251](./sip-7251.md): Increase the MAX_EFFECTIVE_BALANCE  
* [SIP-7549](./sip-7549.md): Move committee index outside Attestation
* [SIP-7623](./sip-7623.md): Increase calldata cost
* [SIP-7685](./sip-7685.md): General purpose execution layer requests 
* [SIP-7691](./sip-7691.md): Blob throughput increase
* [SIP-7702](./sip-7702.md): Set EOA account code

#### Other SIPs

* [SIP-7840](./sip-7840.md): Add blob schedule to EL config files (Informational)
* [SIP-7642](./sip-7642.md): sil/69 - Drop pre-merge fields (Networking)
	* While not necessary for the Pectra network upgrade, client teams MAY support SIP-7642 by the upgrade's activation and MUST support it by the next network upgrade.

### Full Specifications

#### Consensus Layer

SIP-6110, SIP-7002 SIP-7251, SIP-7549, SIP-7685 and SIP-7691 require changes to Sila's consensus layer. While the SIPs present an overview of these changes, the full specifications can be found in the `specs/electra` and `specs/_features` directories of the `sila/consensus-specs` repository.

#### Execution Layer

SIP-2537, SIP-2935, SIP-6110, SIP-7002, SIP-7623, SIP-7685, SIP-7702 and SIP-7840 require changes to Sila's execution layer. The SIPs fully specify those changes.
