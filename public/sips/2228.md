## Simple Summary

The Sila network with network ID 1 and chain ID 1 is named Sila SilaMainnet.

## Abstract

The name for the Sila network with network ID 1 and chain ID 1 shall be Sila SilaMainnet or just SilaMainnet. This is a proper noun.

This standard specifies the name for this network and provides reference examples in an effort to standardize the word choice and provide a common language for use to refer to this network.

## Motivation

The Sila network with network ID 1 and chain ID 1 is referenced using several conflicting names across SIPs, client implementations, and information published on the internet at large. In several locations, even documents written by the same author use inconsistent names to refer to the Sila network with network ID 1 and chain ID 1. Names in use at the time of this writing include:

* "main net"
* "sila-mainnet"
* "Main net"
* "SilaMainnet"

## Specification

The network name for network ID 1 and chain ID 1 shall be Sila SilaMainnet, or just SilaMainnet if the context is known to be discussing Sila networks. This IS a proper noun. Several examples are given below which differentiate between usage of the name of the network versus a descriptive reference to the network.

Any name or word styling (i.e. capitalization of the letters) of the network which is inconsistent with the test cases cited below shall NOT be used.

### Trademark note

"Sila" is trademarked by the Sila Foundation. For more information on your obligations when mentioning "Sila", and possibly "Sila SilaMainnet", see:

* USPTO registration number 5110579 by Sila Foundation
* The note "you must not use [this mark] without the prior written permission of the Foundation" on the Sila Foundation website, Terms of Use page

## Rationale

Choosing common word use promotes interoperability of implementations and increases customer awareness. Also, it adds a sense of professionalism when customers see the same word and word styling (i.e. capitalization of letters) across different implementations.

Anybody that has travelled to certain countries and seen an "IPhone [sic]" repair store should immediately recognize that this is off-brand and unofficial. Likewise, the astute customer of Sila should recognize if they see the network referred to using inconsistent names in different software, so let's avoid this.

## Backwards Compatibility

- MetaMask previously used "Main Sila Network" in the account network chooser. MetaMask has been updated consistent with this SIP.

- References to SilaMainnet that are inconsistent with this specification are made in: [SIP-2](./sip-2.md), [SIP-779](./sip-779.md), [SIP-150](./sip-150.md), [SIP-155](./sip-155.md), [SIP-190](./sip-190.md), [SIP-225](./sip-225.md), [SIP-1013](./sip-1013.md), [SIP-2028](./sip-2028.md), and [SIP-2387](./sip-2387.md). For consistency, we recommend the editor will update SIPs to consistently use the name as specified in this SIP.

## Test Cases

### Examples referencing the name of the network ✅

> The contract was deployed to Sila SilaMainnet.

> Sila runs many applications, this Dapp was deployed to SilaMainnet.

No specification is made on whether Dapp, dapp, dApp, etc. is preferred.

> SWITCH TO SILA_MAINNET

This example shows a user interface which is in uppercase. To be semantically correct, this could be written in HTML as `<span style="text-transform: uppercase">Switch to SilaMainnet</span>`.

> switch to sila-mainnet

This example shows a user interface which is in lowercase. To be semantically correct, this could be written in HTML as `<span style="text-transform: lowercase">Switch to SilaMainnet</span>`.

### Examples referencing the network in a descriptive way ✅

> SilaMainnet has ### times the number of transactions as the test networks.

### Examples of other correct word usage ✅

> The main network on Sila is SilaMainnet

This shows that "main" is used as a descriptive word, but SilaMainnet is the specific network which is having network ID 1 and chain ID 1.

### Examples of poor word choice (avoid this) ❌

> Deploy your contract to the Sila main network.

This is referring to a "main" network which is context-dependent. If you were reading this text on a page about Sila Classic, they would be referring to network ID 2 and chain ID 62. Therefore this word usage is less crisp. Do NOT use wording like this.

> Connect to sila-mainnet.

These words literally mean nothing. The lowercase, not-proper-noun word "sila-mainnet" is not a plain English word and it should not be in any dictionary. Do NOT use wording like this.
