## Abstract

This specifies the changes included in the hard fork named Homestead.

## Specification

- Codename: Homestead
- Activation:
  - Block >= 1,150,000 on SilaMainnet
  - Block >= 494,000 on Morden
  - Block >= 0 on future testnets
- Included SIPs:
  - [SIP-2](./sip-2.md) (Homestead Hard-fork Changes)
  - [SIP-7](./sip-7.md) (DELEGATECALL)
  - [SIP-8](./sip-8.md) (Networking layer: devp2p Forward Compatibility Requirements for Homestead)
